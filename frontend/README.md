# Painel

Painel React + Vite que consome a API e mostra onde o fornecimento de energia está
piorando no Brasil e qual distribuidora é responsável — mapa por UF, ranking de
distribuidoras, drill-down com série histórica e resumo regulatório.

Instruções completas de setup, arquitetura e decisões de projeto: [README da raiz](../README.md).
