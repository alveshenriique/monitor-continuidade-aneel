# API

API NestJS que abre o `indicadores.duckdb` gerado pelo pipeline (somente leitura) e
serve os indicadores de continuidade — ranking de distribuidoras, mapa por UF,
série histórica e enriquecimento regulatório — para o painel React.

Instruções completas de setup, arquitetura e decisões de projeto: [README da raiz](../README.md).
